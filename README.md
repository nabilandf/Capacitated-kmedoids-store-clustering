# Capacitated K-Medoids Store Clustering

Capacitated K-Medoids clustering for balanced BMS territory assignment, store pooling optimization, and spatial coverage analysis across multiple branch areas.

## 📌 Key Features

- Capacitated K-Medoids clustering implementation
- Balanced store allocation across BMS territories
- Haversine distance calculation for geographic clustering
- Medoid-based store pool selection
- Spatial visualization using Folium maps
- Convex Hull area coverage visualization
- Cluster performance evaluation and distance analysis

- Python
- Pandas
- NumPy
- Folium

- SciPy
